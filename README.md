# MediLink Emergency Response & Dispatch UI/UX

A university UI/UX design project focused on creating an emergency response and dispatch management interface for dispatchers and paramedics.

## Project Overview

MediLink is an emergency response and dispatch management interface designed to present critical incident, patient and responder information clearly during emergency situations.

The system was designed across both **desktop and smartwatch interfaces**, with a focus on usability, information clarity and quick access to important emergency information.

## My Role

I was responsible for the **UI/UX design** of the MediLink system.

My work included:

- Understanding the interface requirements and emergency-response context
- Creating low-fidelity wireframes
- Designing user interfaces for desktop and smartwatch experiences
- Developing a scalable Atomic Design System
- Creating high-fidelity interface designs
- Applying usability principles to improve the overall interface
- Preparing developer handoff documentation
- Refining the interface to improve responder identification and access to incidents and available units
